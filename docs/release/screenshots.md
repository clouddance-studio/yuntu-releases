# Screenshot and demo capture plan

These are capture instructions and English caption drafts, not delivered screenshots. Use the final accepted installed build, its English interface, a clean test profile, and an original sample project with known asset rights. Do not submit the website's concept illustrations as real editor screenshots.

| Order | Scene | English caption draft | Required evidence |
| --- | --- | --- | --- |
| 1 | A complete small page in the design workspace | Design a UI with editable layers and precise visual controls. | Page saves and reopens in the accepted build. |
| 2 | Layers and properties for that same page | Refine text, spacing, layout, and appearance in one local project. | Selected element and values match the page. |
| 3 | External AI change and the actual editor result | Work with a connected AI client and inspect changes in the real project. | Actual supported client/model run; do not simulate a successful connection. |
| 4 | An element-specific review comment | Keep review feedback attached to the elements you want to improve. | Actual review target, round, and saved comment. |
| 5 | Standard JSON export completed | Hand off versioned JSON and mappings to your development workflow. | Successful final job and complete export package. |
| 6 | Supported animation preview | Preview supported animation before exporting your work. | Genuine playback in the accepted build, not an editing-history frame. |

For the current MSIX listing route, Microsoft's desktop screenshot guidance specifies PNG at least 1366 × 768 pixels, with captions up to 200 characters. Recheck the actual submission fields when preparing the final assets. See [official screenshot guidance](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msix/screenshots-and-images).

Prefer four to six useful scenes over repeated screenshots. Store logo and other artwork must follow the selected package identity and current listing requirements; the website concept mark is not automatically a confirmed release logo.

Before sharing, inspect every image for credentials, account data, private paths, private assets, and unrelated windows. Record the editor version, source project identity, capture dimensions, caption, and file hash beside the final release record. Never capture account screens containing credentials.

A short demo can follow the same project: create the page, request a small AI revision, inspect the result, add review feedback, and complete JSON export. Only show steps that have genuinely passed for the release. Final capture and the editable sample remain pending acceptance; this preparation has not opened or modified the acceptance team's editor.
